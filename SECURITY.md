# Kebijakan Keamanan

Jangan melaporkan celah keamanan lewat issue publik. Gunakan fitur **Report a vulnerability** (GitHub Security Advisories) pada repositori ini, atau hubungi pemelihara secara pribadi. Sertakan versi, langkah reproduksi, dan dampaknya.

Tinjauan keamanan ada di `docs/security-review.md`; rancangan kripto di `docs/PROTOCOL.md`.
